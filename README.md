# Sesko Hub

Evade farm hub. Build output only — this file is generated, do not edit it here.

## Usage

Paste into your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/zjsuarez/evadeseskohub-dist/main/seskokokoko.lua"))()
```

For it to survive rejoins, put that line in your executor's `autoexec` folder instead of running it
by hand — the hub saves its toggle states and restores them when the script runs again.

## Features

- AFK farm with keep-moving spoof and anti-AFK
- Auto rejoin when downed
- Auto join game from the main menu
- FullBright
- Anti-crash memory ceiling rejoin
- Toggle states persist across rejoins

Right Ctrl toggles the interface.
